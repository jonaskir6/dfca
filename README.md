# Decentralized Federated Clustering Algorithm (DFCA)

- a synchronous simulation of the decentralzied federated clustering algorithm with mnist, emnist and cifar10
- codebase: https://github.com/jichan3751/ifca
- Code for my Bachelor Thesis written at TU-Dortmund (Department of Artificial Intelligence, Prof. Harmeling) and Fraunhofer-ISST (Department of Mobility and Smart Cities, M.Sc. Sebasian Becker)

## Hardware and Software:
- CPU: AMD EPYC 7742 64-Core Processor
- GPU: Nvidia A100 40 GB PCI-E 4.0 SXM4
- Python 3.11.11 (Recommended)
  - jupyter, tensorflow_cpu (2.18.1), matplotlib (3.10.0), scipy (1.15.3), scikit-learn (1.6.1), seaborn (0.13.2), torchvision (0.20.1), torch (2.5.1), numpy (2.0.1), ipyparallel (8.6.1)

## Folders:
- To reproduce the experiments run the notebooks from each 'notebooks' folders. (thesis experiments)
- To run the python experiments run ```python run.py``` (not relevant for thesis and not guaranteed to work).
- The 'old' folder contains deprecated versions and various experiments for debugging and just trying out (not relevant for thesis and not guaranteed to work)
